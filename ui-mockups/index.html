REAN campaign: five layout concepts

Five distinct structural directions for the Damilola Asaleye for REAN President site. Each is a clickable prototype that uses the real campaign copy and covers every section: hero, about, pillars, first 100 days, commitments, newsletter updates and signup. Newsletter items are placeholders shaped to the agreed content contract.

Prototype is the styled, interactive view.Wireframe uses the same layout stripped to structure, with labelled sections.Switch between them with the toolbar at the bottom of each page.
01

Power Line

The whole page hangs off a single circuit line, and each section is a node on it. The pillars branch off as connections, the 100 days work as a meter you click through, and the commitments are switches you turn on.

Mood
Technical, energetic, sector-native
Palette
Type
Space Grotesk + IBM Plex Mono
Best if
You want it to read unmistakably as an energy campaign
PrototypeWireframe
02

Town Hall

The page is built as a conversation. A member asks a question, the candidate answers, and the pillars appear as member questions in an accordion. The 100 days read as a message thread, and the signup asks members what REAN should focus on next.

Mood
Warm, approachable, listening-first
Palette
Type
Fraunces + Work Sans
Best if
The message is “I’m here to listen”
PrototypeWireframe
03

Scorecard

An accountability dashboard. A 100-day tracker sits in the hero, the pillars are a table with status pills, and the phases are tabs with checklists. The commitments appear as tiles and the updates as a filterable progress feed. Every status reads as planned until the work starts, and none of the numbers are invented.

Mood
Credible, organised, transparent
Palette
Type
Inter Tight + JetBrains Mono
Best if
“Transparent delivery” is the lead message
PrototypeWireframe
04

Split Stage

The candidate stays on stage while the content scrolls. A sticky portrait panel on the left holds the name, the section nav (which tracks where you are) and the main call to action, and the agenda scrolls on the right. On mobile the panel collapses into a full-height opening section.

Mood
Personal, confident, editorial-serif
Palette
Type
Instrument Serif + Inter
Best if
The candidate’s presence should carry the site
PrototypeWireframe
05

Scroll Deck

A campaign poster in six full-screen slides with snap scrolling and dot navigation. The headlines are huge. Each pillar becomes a single verb that reveals its detail on hover, the first 100 days are a giant “100”, and the pledges are set in oversized type.

Mood
Bold, high-impact, memorable
Palette
Type
Anton + Inter
Best if
You want maximum impact on mobile and in shared links
